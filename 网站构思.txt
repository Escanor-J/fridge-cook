### 1. 关键词搜索（最基础）
直接搜菜名，比如"番茄炒蛋"。适合已经知道想吃什么的用户。

### 2. 冰箱模式 / 食材选择（最有趣）

用户勾选手边有的食材 → 系统找出**食材匹配度最高**的菜谱，按匹配比例排序。关键逻辑：

```
匹配度 = 已选食材 ∩ 菜谱食材 / 菜谱总食材数
```

UI 上可以做成**食材标签云**，常用食材（鸡蛋、葱、大蒜、豆腐……）直接点选，或者打字输入补充。

### 3. 条件筛选（辅助）
- 难度（初学/中级/高级）
- 耗时（15分钟以内 / 30分钟 / 1小时以上）
- 分类（家常菜 / 汤 / 甜点 / 早餐……）
- 排序（热度 / 评分 / 收藏数）

**厨具筛选**：从`tip`和`steptext`里用关键词检测（"烤箱"、"空气炸锅"、"微波炉"、"砂锅"），可以提取出来单独标记，但要做额外的 NLP 预处理，demo 阶段可以先跳过。

## 数据清洗规则

### 通用规则
- 所有字符串字段 strip 首尾空白和换行符
- NULL / NaN 统一存为数据库 NULL，不要存空字符串

### #号分隔字段处理（yl / fl / steptext / steppic）
```python
def split_hash(s):
    if not s or pd.isna(s):
        return []
    return [item.strip() for item in str(s).split('#') if item.strip()]
```
- `yl` 和 `fl` 按索引对齐，zip 成 (食材名, 用量) 元组列表
- 若 fl 比 yl 短，缺少的用量用空字符串填充
- `steptext` 和 `steppic` 同样 zip，steppic 可以比 steptext 短

### 食材名清洗
- 去掉食材名中的括号及括号内容，如 "盐（适量）" → "盐"
- 去掉前后数字和标点，如 "1. 花菜" → "花菜"
- 保留食材名在 1~20 个字符之间的项，其余丢弃
- 食材名去重时不区分全角/半角空格

### 分类字段处理（cid）
- 按中文逗号 `，` 或英文逗号 `,` 分割
- 每个分类名 strip 后存入 recipe_categories 表

### 难度映射
```python
DIFFICULTY_MAP = {0: '初级', 1: '中级', 3: '高级'}
```

### 视频 URL 处理
检测 videourl 所属平台，写入 video_platform 字段：

```python
def detect_platform(url):
    if not url or pd.isna(url):
        return None
    url = str(url).lower()
    if 'youku.com' in url:
        return 'youku'
    elif 'bilibili.com' in url or 'b23.tv' in url:
        return 'bilibili'
    elif 'tudou.com' in url:
        return 'tudou'
    elif 'iqiyi.com' in url or 'iqiyi' in url:
        return 'iqiyi'
    elif 'v.qq.com' in url:
        return 'tencent'
    else:
        return 'other'
```

videourl 字段原样保存，不做修改。

## 输出：SQLite 数据库 Schema

输出文件路径：`./data/recipes.db`

### 建表 SQL

```sql
-- 菜谱主表
CREATE TABLE IF NOT EXISTS recipes (
    id          INTEGER PRIMARY KEY,
    did         TEXT,
    title       TEXT NOT NULL,
    thumb       TEXT,
    video_url   TEXT,
    video_platform TEXT,          -- 'youku'/'bilibili'/'tudou'/'iqiyi'/'tencent'/'other'/NULL
    description TEXT,
    difficulty  INTEGER,          -- 0/1/3
    difficulty_label TEXT,        -- '初级'/'中级'/'高级'
    cost_time   TEXT,
    tip         TEXT,
    main_category TEXT,
    grade       REAL,
    cook_count  INTEGER,
    view_count  INTEGER,
    fav_count   INTEGER
);

-- 食材去重表（用于冰箱模式食材列表）
CREATE TABLE IF NOT EXISTS ingredients (
    id   INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL
);

-- 菜谱-食材关联表
CREATE TABLE IF NOT EXISTS recipe_ingredients (
    recipe_id     INTEGER NOT NULL,
    ingredient_id INTEGER NOT NULL,
    amount        TEXT,
    sort_order    INTEGER,
    PRIMARY KEY (recipe_id, ingredient_id),
    FOREIGN KEY (recipe_id)     REFERENCES recipes(id),
    FOREIGN KEY (ingredient_id) REFERENCES ingredients(id)
);

-- 菜谱分类表
CREATE TABLE IF NOT EXISTS recipe_categories (
    recipe_id INTEGER NOT NULL,
    category  TEXT    NOT NULL,
    is_main   INTEGER DEFAULT 0,   -- 1 表示主分类(zid)
    PRIMARY KEY (recipe_id, category)
);

-- 烹饪步骤表
CREATE TABLE IF NOT EXISTS recipe_steps (
    id         INTEGER PRIMARY KEY AUTOINCREMENT,
    recipe_id  INTEGER NOT NULL,
    step_num   INTEGER NOT NULL,
    step_text  TEXT,
    step_pic   TEXT,
    FOREIGN KEY (recipe_id) REFERENCES recipes(id)
);
```

### 索引（建完表后创建）
```sql
CREATE INDEX IF NOT EXISTS idx_recipes_difficulty ON recipes(difficulty);
CREATE INDEX IF NOT EXISTS idx_recipes_grade      ON recipes(grade);
CREATE INDEX IF NOT EXISTS idx_recipes_main_cat   ON recipes(main_category);
CREATE INDEX IF NOT EXISTS idx_recipe_ing_ing     ON recipe_ingredients(ingredient_id);
CREATE INDEX IF NOT EXISTS idx_ing_name           ON ingredients(name);
```
